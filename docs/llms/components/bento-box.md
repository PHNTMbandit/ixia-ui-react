# Bento Box

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Bento Box component is a versatile container that allows for the organization of content into a structured and visually appealing layout. It provides a clean and modern design, making it suitable for various use cases, such as dashboards, cards, or any scenario where content needs to be presented in a compact and organized manner.

## Import

```tsx
import { BentoBox } from 'ixia-ui-react/bento-box'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `size`: Sets the size of the bento box, affecting padding and spacing. Options: `small`, `medium`, `large`. Storybook-reported default: `medium`.
