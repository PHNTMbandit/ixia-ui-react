# Nav Bar

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

NavBar is a compact bottom navigation surface composed of `NavBarItem`, `NavBarItemIcon`, and `NavBarItemLabel`. It supports three sizes, two visual variants, and per-item tone coloring. Vertical items share the available width as squares, with compact width caps for small and medium sizes; long labels truncate to keep items within the bar.

## Import

```tsx
import { NavBar } from 'ixia-ui-react/nav-bar'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `size`: Options: `small`, `medium`, `large`. Storybook-reported default: `medium`.
- `variant`: Options: `outline`, `floating`. Storybook-reported default: `outline`.
