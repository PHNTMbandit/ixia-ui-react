# Tabs

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Tabs component allows users to navigate between different sections of content within the same context. Each tab corresponds to a panel that displays related information when selected.

## Import

```tsx
import { Tabs } from 'ixia-ui-react/tabs'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `fill`: Whether tabs should fill available width. Storybook-reported default: `true`.
- `showBorder`: Whether underline tabs show a bottom border. Storybook-reported default: `true`.
- `size`: Size of the tabs and indicator. Options: `small`, `medium`, `large`. Storybook-reported default: `medium`.
- `tone`: Color tone of the tabs. Options: `brand`, `accent`, `neutral`, `error`, `info`, `success`, `warning`. Storybook-reported default: `brand`.
- `variant`: Visual style of the tabs list. Options: `default`, `ghost`, `underline`. Storybook-reported default: `default`.
