# Separator

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

Separator visually partitions related content while preserving layout rhythm. It supports horizontal and vertical orientation, multiple thickness weights, and style/variant options for subtle or stronger emphasis. Common use cases include menus, sidebars, toolbars, and card sections.

## Import

```tsx
import { Separator } from 'ixia-ui-react/separator'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `orientation`: Direction of the dividing line. Options: `horizontal`, `vertical`. Storybook-reported default: `horizontal`.
- `style`: Corner treatment of the separator line. Options: `rounded`, `square`. Storybook-reported default: `rounded`.
- `variant`: Visual emphasis token for separator color. Options: `default`, `strong`. Storybook-reported default: `default`.
- `weight`: Thickness of the separator line. Options: `thinnest`, `thin`, `medium`, `thick`. Storybook-reported default: `thinnest`.
