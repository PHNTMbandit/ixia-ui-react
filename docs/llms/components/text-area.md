# Text Area

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The TextArea component provides a multi-line input field that allows users to enter and edit larger amounts of text. It supports visual variants, max length feedback, and disabled states for form workflows.

## Import

```tsx
import { TextArea } from 'ixia-ui-react/text-area'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `disabled`: Disables editing and interactions. Storybook-reported default: `false`.
- `maxLength`: Maximum characters allowed. Shows character counter when set.
- `placeholder`: Placeholder text shown when empty.
- `rows`: Visible number of text rows.
- `variant`: Visual style for the textarea container. Options: `primary`, `secondary`. Storybook-reported default: `primary`.
