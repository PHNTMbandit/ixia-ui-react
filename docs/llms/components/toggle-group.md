# Toggle Group

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

Toggle Group organizes related toggles into one control. It supports single selection by default and multiple selections when enabled.

## Import

```tsx
import { ToggleGroup } from 'ixia-ui-react/toggle-group'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `multiple`: Allow selecting multiple toggles at once. Storybook-reported default: `false`.
- `size`: Size of the toggle group and its toggles. Options: `small`, `medium`, `large`. Storybook-reported default: `medium`.
- `variant`: Visual style of the toggle group. Options: `default`, `ghost`. Storybook-reported default: `default`.
