# Kbd

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Kbd component highlights keyboard keys or shortcut combinations in compact keycap styling. Use it alongside buttons, inputs, command palettes, and instructional content. Compose multiple keys with `KbdGroup` for modifier and sequence combinations.

## Import

```tsx
import { Kbd } from 'ixia-ui-react/kbd'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `children`: Shortcut label shown inside the keycap. Storybook-reported default: `Ctrl + K`.
