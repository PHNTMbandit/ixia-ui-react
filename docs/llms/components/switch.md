# Switch

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Switch component allows users to toggle between two states, such as on and off. It is commonly used in forms and settings to represent binary options. The Switch can be customized with different states to fit various design needs.

## Import

```tsx
import { Switch } from 'ixia-ui-react/switch'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `checked`: Controlled checked state Storybook-reported default: `undefined`.
- `defaultChecked`: Initial uncontrolled checked state Storybook-reported default: `false`.
- `disabled`: Disable the switch interaction Storybook-reported default: `false`.
- `id`: HTML id attribute for the switch button Storybook-reported default: `undefined`.
