# Skeleton

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Skeleton component is used to display placeholder loading skeletons while content is being fetched or loaded. It provides a visual indication to users that data is being loaded, enhancing the user experience during wait times.

## Import

```tsx
import { Skeleton } from 'ixia-ui-react/skeleton'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `children`: Nested content (rarely used for basic skeletons) Storybook-reported default: `undefined`.
- `className`: Custom CSS classes to style the skeleton Storybook-reported default: ` rounded-lg`.
