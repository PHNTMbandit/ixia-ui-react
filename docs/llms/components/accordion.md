# Accordion

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Accordion component displays collapsible content panels. Items support multiple tones (`brand`, `accent`, `neutral`, `error`, `info`, `success`, `warning`) and two layout variants (`surface`, `ghost`). Multiple panels can optionally be open at once via the `multiple` prop on the root.

## Import

```tsx
import { Accordion } from 'ixia-ui-react/accordion'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `size`: Options: `small`, `medium`, `large`.
- `tone`: Options: `brand`, `accent`, `neutral`, `error`, `info`, `success`, `warning`.
