# Toggle

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Toggle component allows users to switch between two states, such as on and off. It supports text and icon-only variants, multiple visual sizes, and semantic tones.

## Import

```tsx
import { Toggle } from 'ixia-ui-react/toggle'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `disabled`: Disables the toggle interaction. Storybook-reported default: `false`.
- `size`: Size and layout of the toggle. Options: `small`, `medium`, `large`, `iconSmall`, `iconMedium`, `iconLarge`.
- `tone`: The tone of the toggle, which determines its color scheme. Options: `brand`, `accent`, `neutral`, `error`, `info`, `success`, `warning`. Storybook-reported default: `brand`.
