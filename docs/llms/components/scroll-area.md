# Scroll Area

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

ScrollArea provides a polished container for content that exceeds its visible bounds. It supports vertical and horizontal orientation, styled scrollbars, and subtle edge gradients that hint at additional content. Use it for article sections, chat logs, media rails, activity lists, and any constrained layout where native overflow would feel too raw.

## Import

```tsx
import { ScrollArea } from 'ixia-ui-react/scroll-area'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `orientation`: Sets scroll direction and scrollbar axis. Options: `vertical`, `horizontal`. Storybook-reported default: `vertical`.
- `variant`: Applies a preset combination of background, borders, and viewport padding. Options: `default`, `ghost`, `outline`. Storybook-reported default: `default`.
