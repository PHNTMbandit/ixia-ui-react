# Alert Dialog

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Alert Dialog component blocks interaction with the rest of the application until the user explicitly confirms or cancels. It supports seven semantic tones (`brand`, `accent`, `neutral`, `error`, `info`, `success`, `warning`) that color the leading icon and the confirm button.

## Import

```tsx
import { AlertDialog } from 'ixia-ui-react/alert-dialog'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.

- `tone`: Sets the semantic tone of the dialog, coloring the icon and confirm button. Options: `brand`, `accent`, `neutral`, `error`, `info`, `success`, `warning`. Storybook-reported default: `brand`.
