# Slider

> Generated from Ixia public exports and Storybook descriptions. Run `vp run docs:llms` to update.

The Slider component allows users to select a value from a continuous or discrete range by dragging a thumb along a track. It is commonly used in forms and settings where users need to adjust values such as volume, brightness, or other numerical inputs. The Slider can be customized with different sizes, tones, and step values to fit various design needs.

## Import

```tsx
import { Slider } from 'ixia-ui-react/slider'
```

## Selected Storybook controls

These controls are a partial guide and may include example-specific values. Storybook-reported defaults can differ from component defaults; see the TypeScript types and implementation for the complete API.
